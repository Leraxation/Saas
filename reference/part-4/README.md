# Part 4 — Jeep Gladiator "Desert Chief"

Three reference photographs were supplied for this vehicle but not committed:
they arrived in conversation without files on disk. The build was described
from them and that description lives in the vehicle's `brief` in
`lib/vehicles/manifest.ts`, which is what the generation prompt uses.

To commit them, drop the three images in this folder and replace the part's
`count: 3` with an `images: [...]` array in the manifest.
